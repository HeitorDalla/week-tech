# Adaptadores (Adapters)
Gerencia a exibição de listas dinâmicas no app.
Conecta os dados das entidades aos componentes de UI.

Arquivos criados:
- `EventScheduleAdapter.java` - lista de palestras/programação.
- `SpeakerAdapter.java` - lista de palestrantes.
- `ProjectAdapter.java` - lista de projetos cadastrados.
- `SponsorAdapter.java` - lista de patrocinadores.
- `FaqAdapter.java` - lista de perguntas e respostas (FAQ).
- `ParticipantAdminAdapter.java` - lista administrativa de participantes.
